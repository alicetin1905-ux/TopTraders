How this works

A scheduled job snapshots each exchange's leaderboard and open positions. The page then re-prices every position in your browser against live oracle and mid prices, so PnL, notional value and ROE stay current between snapshots.

Alerts: add this to your Home Screen, then turn on Alerts to be told when a starred trader trades. Notifications arrive while the app is open or recently backgrounded. Delivery when it is fully closed needs a push service holding subscriptions, which static hosting cannot provide — see the README for that option.
